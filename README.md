<h3 id="developer-utilities">Developer Utilities</h3>

> Practical tools for development, debugging, data handling, documentation, and everyday workflows.

- [CSVTool](https://csvtool.com) — browser-based tools for viewing, editing, and converting CSV files.

- [CustomGraph](https://customgraph.com) — generate and print custom graph paper and worksheets.
- [VisuAlgo](https://visualgo.net) — visualizations of data structures and algorithms.
- [ASCII Art Archive](https://asciiart.eu/image-to-ascii) — image-to-ASCII converter and ASCII art collection.
- [TinyWow](https://tinywow.com) — free tools for PDF, image, writing, and other tasks.
- [JSON Crack](https://jsoncrack.com) — visualize JSON and YAML as interactive graphs.
- [Efecto](https://efecto.app) — turn images into dither or ASCII art.
- [ICQR Magic Tree](https://tree.icqr.com) — creative 3D QR code generator.
- [Eraser](https://eraser.io) — create clean system design diagrams.
- [DevDocs](https://devdocs.io) — searchable documentation for programming languages and APIs.
- [Kaggle Learn](https://kaggle.com/learn) — interactive courses for Python, SQL, data science, and more.
- [Pydle](https://pydle.net) — Wordle-style game for Python concepts.
- [PyUiBuilder](https://pyuibuilder.com) — drag-and-drop GUI builder for Python applications.
- [Responsively](https://responsively.app) — responsive web development and testing tool.
- [Cubic Bezier](https://cubic-bezier.com) — interactive cubic-bezier timing-function editor.
- [CSS-Tricks Almanac](https://css-tricks.com/almanac/) — reference for CSS properties and web development.
- [Codecrafters](https://codecrafters.io) — build your own Redis, Docker, Git, and more through guided real-world coding challenges.
- [Cobalt](https://cobalt.tools) — free, open-source tool for downloading video and audio from social platforms and websites.
- [Repolyze](https://repolyze.mxcorp.in) — repository analysis tool.
